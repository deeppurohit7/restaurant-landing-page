# Saffron & Sage — Artisan Restaurant Landing Page

A responsive culinary brand landing page built from scratch with pure HTML5 and CSS3.

## Live Demo
- **Live Site:** `https://deeppurohit7.github.io/restaurant-landing-page/`
- **Source Code:** `https://github.com/deeppurohit7/restaurant-landing-page`

## Features
- **Pure CSS Filter Tabs:** Interactive category switching (Starters, Mains, Desserts) using hidden radio inputs and sibling selectors without JavaScript.
- **Styled Booking System:** Fully accessible table reservation form with custom focus rings and layout controls.
- **Warm Editorial Typography:** High-contrast pairing of *Playfair Display* and *Plus Jakarta Sans*.
- **Responsive Layout:** Adapts smoothly across desktop monitors, tablets, and mobile devices.
